## How to Capture

1. Run: `npm run dev`
2. Open http://localhost:3000
3. Sign up → Create team → Create session → Add content
4. Test real-time: open two browsers, edit same draft
5. Test AI: paste article URL in session → wait for analysis
6. Save as PNG at 1200x800
